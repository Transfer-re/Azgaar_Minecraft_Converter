## Judgement calls

- **Adansonia_digitata** -- pale trunk wood and darker branch wood kept apart
- **Adansonia_grandidieri** -- pale trunk wood and darker branch wood kept apart
- **Bismarckia_nobilis** -- downy willow is the palest CR leaf, for the silver fronds
- **Ceiba_pentandra** -- mallorn_log for the pale buttressed giant
- **Colophospermum_mopane** -- wisteria_leaves for the butterfly leaf
- **Delonix_regia** -- bipinnate; CR has no red flowering leaf
- **Podocarpus_milanjianus** -- a true conifer; cypress_leaves is the only untinted CR leaf used here, so it stays dark in a savanna
- **Sideroxylon_spinosum** -- argan really is olive-like, so CR olive is the right block
- **Uapaca_bojeri** -- source uses pale_oak, which does not exist before 1.21.4
- **Vachellia_xanthophloea** -- aspen_log is the palest CR log, for the yellow-green bark
